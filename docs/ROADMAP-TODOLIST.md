## 2. 规划（轮次视图）

```
R31 ✅ 设计器字段深度（G15–G18/G19a）
R32 ▶ 数据编辑器收口（G2 已写待收 → G3 → G4 → G19b → 修 D-1/D-2/D-3）   ← 当前
R33    导入导出深度 + 连接高级（G5 → G6 → G20 → G8 → PG 联调）
R34    查询补全（G10）→ 详细信息视图（G9）→ 结构页预览（G11）→ 多库（G12 逐库）
之后   V1 视图 / N1–N3 / 主题跟随系统 / 冷启动 / 暗色全量 30 帧
```

**排序理由**：① R32 里 G2 已有未提交代码，先收口避免烂尾；
② 数据编辑器是打开表之后停留时间最长的界面（G3/G4 直接决定「像不像 Navicat」的手感）；
③ 连接高级（G8）是本次五张实拍里**形状差距最大**的一块（磁贴页 + 7 页签 vs 三步向导），但使用频次低于数据编辑器，故排 R33；
④ P1 各项彼此独立，按「日常使用频率」排序。

**每轮固定验收口径**（真源 §9）：全量门禁 0 失败 + 新能力带行为门禁与变异验证 + 涉视觉必重拍帧逐张目视 + 回填真源三处 + 分批本地提交（push 需单独授权）。
