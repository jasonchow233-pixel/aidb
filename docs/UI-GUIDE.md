# UI 指南

> 面向实现的 UI 规则。数值令牌以
> `ui/adb-ui-core/src/main/resources/tokens/tokens.json` 为唯一真相；
> 交互清单以 `NAVICAT-TODO.md` 为准；
> 与 Navicat 的差距以 `docs/NAVICAT-GAP.md` 为准。

---

## 1. 视觉基线

- **原生窗口**：`StageStyle.DECORATED`，不自绘标题栏；macOS 菜单进入系统菜单栏。
- **密度**：桌面工具密度，行高 28px 左右；默认 13px 字体，辅助文案 11–12px。
- **主题**：亮色是评审基准；暗色与亮色共享同一组语义令牌。
- **颜色**：业务 CSS 不写 `#rrggbb` / `rgba(...)`，只引用 `-adb-*` looked-up colors。
- **圆角/间距**：控件 6–8px，面板 8–10px；页面外边距 16px，工具栏 8px。
- **图标**：首版使用系统可显示的 Unicode 符号，避免额外图标字体依赖。

### 令牌生成

```bash
java tools/GenTokens.java
```

生成：

- `ui/adb-ui-core/src/main/java/io/agenticdb/ui/Tokens.java`
- `ui/adb-ui-core/src/main/resources/io/agenticdb/ui/theme-dark.css`
- `ui/adb-ui-core/src/main/resources/io/agenticdb/ui/theme-light.css`

`TokenParityTest` 校验 JSON 键与 `Tokens.ALL_KEYS` 完全一致，并扫描业务 CSS。

**已知缺口**（→ `NAVICAT-TODO.md` 4.5-14）：

- 生成器只把 **color 类型**令牌导出成 CSS，65 个非颜色令牌（`fs-*` `sp-*` `r-*` `h-*`
  `w-*` `z-*` `dur-*` `ease-*` `lh-*` `fw-*` `shadow-*` …）永远不会出现在 CSS 里。
- 120 个令牌中只有 41 个被 `app.css` 引用，其余 79 个是摆设。

### 图标约定

**一套图标只表一个意思。** 已知撞车与待统一项：

| 符号 | 问题 | 处理 |
|---|---|---|
| `⚙` | 同时表示“结构”和“设置”（`TabKind.STRUCTURE` / `TabKind.SETTINGS`） | 必须拆开（4.5-5） |
| `↻` / `⟳` | 同一个“刷新”有两种字形 | 统一为 `↻` |
| `✕` / `×` | 同一个“关闭”有两种字形 | 统一为 `✕` |
| `⌕` / `🔍` | 放大镜用了两个码位，且 `⌕` 的 Unicode 名是「电话录音机」 | 统一一个码位 |
| `⌄` | 用下箭头冒充漏斗 | 换成真正的漏斗字符或 SVG |
| `🔍` `🔑` | 非 BMP 彩色 emoji，与相邻的 `•` 视觉重量不一致 | 与单色符号统一 |

**可访问性**：所有图标按钮必须调用 `setAccessibleText("刷新")` 这类文本，
读屏软件才能读出语义而不是读出符号（→ 4.5-6）。

## 2. 六区布局

| 区域 | 规则 |
|---|---|
| 菜单栏 | 原生菜单；macOS 使用系统菜单栏；所有项走 `ActionRegistry` |
| 主工具栏 | 高频动作；危险动作不放在第一排 |
| 侧栏 | 展开 240px / 折叠 48px，可拖动；对象树按连接 → 表/视图分组 |
| 标签栏 | 每标签独立状态；切表不串页、不丢分页位置；关闭脏标签需确认 |
| 内容区 | 页面自行管理加载/空/错误三态 |
| 状态栏 | 连接、行范围、耗时、脏计数、只读/错误状态；26px |

**状态栏字段**：`DEV` 环境标记、连接名、行范围、消息、脏计数、选择数、耗时、事务、只读、版本。

**已知缺口**：`setEnv` / `setSelection` / `setTransaction` 三个 setter 零调用，
所以 `DEV` / `未选择` / `自动提交` 永远是这三个值（→ 4.5-11）。

## 3. 组件与交互规则

### 3.1 动作与快捷键

- 菜单、工具栏、右键菜单、命令面板共用 `ActionRegistry`，不允许各自判断 enabled。
  **已知例外**：侧栏树右键菜单、侧栏导航按钮、工具栏图标按钮三处仍走独立路径
  （→ 4.5-8 / 4.5-9 / 4.5-10）。
- 表格内快捷键：`⌘Z` 撤销、`⇧⌘Z` 重做、`⌘S` 保存、`⌘F` 本页搜索、
  `⌘C` 复制值、`⌥⌘C` 复制 TSV、`⇧⌘C` 复制 INSERT、`⌘A` 全选当前页。
  **⛔ 后四个尚未实现**（→ 4.5-1）。
- 查询页快捷键：`⇧⌘N` 新建查询、`⌘O` 打开 SQL、`⌘R` 执行当前语句、`⇧⌘R` 执行全部、
  `⌘.` 取消、`⌘E` 执行计划、`⌥⇧F` 格式化、`⌘/` 注释、`⌘S` 保存、`⌘F` 查找、`⌘G` 下一个、`⌃H` 替换。
- 文本输入框聚焦时，不抢 `⌘Z` / `⌘F` 等编辑快捷键。

### 3.2 数据页

- **只读优先**：视图、无主键表显示只读标记，编辑/新增/删除全部禁用。
- **NULL ≠ 空串**：NULL 显示 `NULL`，空串显示 `""`；右键菜单分别提供“设为 NULL”“设为空串”。
- **脏标记**：编辑单元格左侧竖条/淡色底；删除行淡红；新增行淡绿。
- **保存**：先弹 SQL 预览，确认后在单事务执行；失败整体回滚并保留缓冲。
- **撤销保存**：保存成功 Toast 提供“撤销”，执行保存前生成的反向 SQL；有新的未保存编辑时不再提供。
- **批量条**：选中行后出现；复制 TSV / 复制 INSERT / 克隆 / 设 NULL / 设空串 / 删除；
  整批操作只占一个撤销栈位。
- **视图**：本页搜索、隐藏含 NULL 行、隐藏含空串行、只读转置；都不改服务端分页。
- **列**：列头单击排序（Shift 多列，最多 3 级），双击自适应宽度；列宽/顺序/显隐持久化。
- **详情抽屉**：文本 / JSON / Hex / 图片 / 元数据；大字段按 Tab 懒加载；Esc 关闭。
- **导出**：当前页 CSV（UTF-8 BOM）、复制当前页 TSV、复制当前页 INSERT。
- **分页**：只有 `‹ 上一页` / `下一页 ›`，没有首末页与跳页（→ 对标差距）。

### 3.3 查询页

- **编辑器**：等宽字体、行号、当前行淡背景；关键字/字符串/数字/注释/参数使用 `-adb-syn-*` token。
- **风险提示**：编辑器右上角常驻“只读 / 写入 / 结构变更 / 管理”徽标；写操作执行前二次确认并展示 SQL。
- **执行**：`⌘R` 只跑光标所在语句，`⇧⌘R` 跑全部；每条语句一个结果页签。
- **结果**：结果集只读表格复用 P2 单元格渲染；消息页显示影响行数；错误页显示可读原因并定位编辑器。
- **取消**：运行中显示取消按钮；取消后丢弃迟到回调，不覆盖新结果。
- **查找替换**：查找栏内嵌在编辑器上方，不弹出独立窗口；替换只作用于当前查询文本。
- **格式化/注释**：格式化只改空白与关键字大小写；注释使用 `-- ` 前缀，支持多行切换。
- **历史**：最近 50 条，去重，保存在 `java.util.prefs`；首版不提供跨设备同步。

### 3.4 结构页

- **五个页签**：列 / 索引 / 外键 / 触发器 / DDL。
- **只读优先**：索引、外键、触发器、DDL 全部只读；视图整体只读。
- **可编辑范围**：仅列——新增列、修改可空 / 默认值 / 注释 / 唯一、重命名列、删除列。
- **危险分级**：改列与删列要两级确认（先展示将要执行的 SQL，再确认高风险）。
- **主键保护**：主键列不能直接删除，提示先调整主键。
- **事务**：结构变更单事务执行，失败整体回滚；SQLite 走整表重建（临时关外键）。
- **联动**：结构变更成功后刷新对象树与所有已打开的数据页 / 结构页。
- **DDL 来源提示**：PostgreSQL 无 `SHOW CREATE TABLE`，DDL 区域必须标注「由内省生成的等价 DDL」。

### 3.5 连接管理页与连接向导

**连接管理页**

- 列表显示：名称（收藏带 `★`）、类型 + 目标（已连接追加“已连接”）。
- 工具条：`＋ 新建连接` / `打开` / `编辑` / `复制` / `删除` / `↻ 刷新`。
- 过滤：搜索框（名称 / 主机 / 库 / 用户）+ “只看收藏”勾选。
- 删除必须二次确认，且**默认按钮不能是“删除”**（→ 4.5-7）。

**连接向导（三步）**

| 步骤 | 内容 |
|---|---|
| 1 类型与名称 | 数据库类型下拉、连接名称 |
| 2 连接参数 | SQLite：文件路径 + 浏览；服务器：主机 / 端口 / 数据库 / 用户名 / 密码 |
| 3 测试与保存 | 参数摘要、测试连接、结果、目标摘要 |

- 可回退且**不丢输入**；校验错误写在**常驻的错误行**里（第 1、2 步看不到第 3 步的摘要区）。
- 口令只在保存时写入 `CredentialStore`，`ConnectionProfile` 里不存口令。
- ⛔ 导航按钮（“上一步 / 下一步 / 测试连接”）**不能**放进
  `dialog.getDialogPane().getButtonTypes()`：JavaFX 的 `DialogPane.createButton`
  会给每个按钮栏按钮挂 `setResultAndClose` 处理器，点一下就关闭整个对话框。
  导航按钮放内容区，只有“保存 / 取消”用原生按钮；“保存”用 `ActionEvent` 过滤器做校验，
  校验不过 `event.consume()` 阻止关闭。

### 3.6 反馈

- 加载：骨架/进度指示，禁止 UI 线程阻塞。
- 空态：说明为什么空 + 下一步动作。
- 错误：可读原因 + 重试；危险操作二次确认，默认按钮不是破坏性动作。
- Toast：1.8 秒；带“撤销”的操作延长到 6 秒。

## 4. 可访问性与键盘

- 所有可点击控件必须可 Tab 到达；表格支持方向键移动焦点。
- 禁用态与只读态必须视觉可区分，不能只靠颜色。
- 错误不能只靠 Toast；状态栏或对话框保留可追溯信息。
- 单元格 Tooltip 对截断文本、NULL/空串、BLOB 大小、枚举映射给出完整解释。
- 图标按钮必须有 accessible text（→ 4.5-6）。
- 对比度：当前只有人工评审，没有自动检查（→ P7）。
