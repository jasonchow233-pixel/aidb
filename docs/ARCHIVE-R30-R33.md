### R31 · 表设计器字段深度（G15–G18/G19a）
- **G15 自增列**：`ColumnSpec.autoIncrement` + 三方言各自语序锁死
  （MySQL `AUTO_INCREMENT` 排在 `PRIMARY KEY`/`COMMENT` **之前**；PG `GENERATED BY DEFAULT AS IDENTITY` 排在 `NOT NULL` 前；
  SQLite 只有 `INTEGER PRIMARY KEY AUTOINCREMENT` 这一种能让 rowid 别名真生效）。
  六条拒绝规则走在生成 SQL 之前：多列自增、自增非主键、自增非整型、自增带默认值、SQLite 用 `INT` 而非 `INTEGER`、SQLite 自增进复合主键。
- **G16 类型结构化**：类型下拉（候选来自 `Dialect.columnTypes()`）+ 长度 + 小数三列分开；
  `rawType` ↔ (类型/长度/小数) 双向映射；换类型自动丢掉新类型吃不下的参数（`DECIMAL(10,2)` → `INT` 不留 `,2`）；
  类型不吃参数时两格**置灰**；非法输入中文拒绝（非数字长度 / 小数>长度 / 有小数无长度）并跳回字段页。
- **G17 字段属性面板**：网格下方常驻 默认值/字符集/排序规则；`supportsColumnCharset()` 只在 MySQL 为真、
  `columnCharsetPresets()`/`columnCollationPresets()` 由每种方言自报、`ColumnTypes.isTextual()` 管「只有文本类型能吃字符集」；
  UI 里不写 `kind() == MYSQL`（`DialectBranchAuditTest` 拦这条，本轮真的拦下过一次）。
- **G18 列顺序**：工具条五键（添加/插入/删除/上移/下移）+ `字段数：N`；插入落在选中行之前、首末越界不动、顺序直接改 `CREATE TABLE` 列序。
- **G19a**：字段网格行高 30 → `RowHeights.of("normal")` = 21px；页签补**备注**（表注释独立成页）。
- **两处与规划的偏离**：① 默认 `id` 行**直接勾上自增**（规划原写「不自动勾，创建前提醒」）——
  Navicat 用户从不想这件事，弹一句提醒等于把负担还给用户；② Binary / Key Length 两格与 Virtual 当时未做。
  → **命运**：功能保住；②的三个缺口在 **R41 N29** 收口（旧「不做」裁定作废）。

## 2. 工程教训（与 Navicat 无关，必须留）

1. ⭐ **CSS 门禁不许只断言「选择器存在 + 含某令牌」** —— 要连**权重与声明顺序**一起比。
   R31 的实况：四处表格作用域的条纹档写成 `:filled:odd`（比所有行态档多一个伪类 = 重 10），
   把 hover / selected / `--deleted` / `--new` 整档压掉 —— 表现成**只有奇数行掉色**，
   而以往每张帧选中的都是偶数行下标，所以从没被看见。
   **门禁全绿，帧里却是白的。** 现成门禁：`SelectionStateTest.stateRulesOutweighTheZebraStripeInEveryTableScope`
   （逐作用域把行态档全捞出来，逐条比权重不低于条纹档、且声明位置在条纹档之后，并断言「至少比过一条」，
   防止选择器换个写法后静默变成零断言）。
   第一版还修错了：补一条 `.adb-dialog .table-view .table-row-cell:selected` → 门禁绿、**帧照样没色**。
   正解是**把条纹降回一个伪类**（`:filled:odd` → `:odd`，空行交给同权重、声明在后的 `:empty`），
   而不是给每条行态档都补 `:filled` —— 前者一次修完四个作用域，后者每加一条新态就得记住补一次。
2. **帧是最后一道，不是装饰。** R31 目视抓出 4 类问题（选中行没色 × 2 张帧、SQLite 会话的字符集格被灰着却填了
   `utf8mb4` —— 摆态写死 MySQL 的值，等于拍出一张自相矛盾的图）。修法：摆**本方言自己的**候选，
   候选为空就留空，让置灰原因自己说话。
3. **像素带阈值的门禁容易被蒙混**（见上条 5 的 `ComboCellRenderingTest`）—— 能写结构断言就别写像素断言。
4. **主题类必须挂在场景根**；子场景（弹窗/AppBar 挪出的工具条）不继承 → 颜色静默变黑。
5. **节点 id 里带 `.` 不能用 `lookup("#…")`**，改为遍历按 `getId()` 比对。
6. **摆拍时序竞态**：选中在数据到位前发出，会被后续刷新顶掉后落在未定义位置
   （R31 的 `p2-cell` 连续三次分别落第 15/12/~10 行）。已随重拍收口；
   仍欠一条「抽屉记录 = 选中行」的自洽断言，以及「奇数下标行选中」固定成摆态口径。
7. **门禁改判 = 改判**：口径变了要同步改门禁并写明理由，绝不"改绿"；每条门禁配一次变异验证（破坏 → 恰好 N 红 → 还原 → 绿）。
8. **占位要么接要么删**：不留永久禁用的菜单项、不留界面上没有任何去向的空壳入口。
   做不到真功能时给**如实说明页**（SSH/HTTP 先例），不给假开关。
   —— 这条在新版里被**保留为诚实条款**，与「一模一样」的冲突点全部按它解决（N19 `Fill with AI`、N27 磁贴、N29 `Ask AI`、N28 六格）。
9. **令牌失去最后一个消费者就删除**，不硬造消费方。
10. **成功静默**：状态栏不播报"执行完成"，只有错误说话。
