# Roadmap

> 公开路线：**现在支持什么 · 接下来做什么 · 明确不做什么**。
> 内部执行清单（逐轮拆解、验收口径）不在本仓库发布，本文只对外承诺结果。

---

## 已支持

| 能力 | 说明 |
|---|---|
| 数据库 | SQLite · MySQL · PostgreSQL · MariaDB · SQL Server · Oracle（后五家全部在本机 Docker 真库矩阵上跑过；MySQL 只有 8.x 有执行证据，5.7 见 `docs/STATUS.md` §测试环境） |
| 形态 | 原生桌面（Java 25 + JavaFX 25），**不内嵌浏览器、不启本地 HTTP 端口** |
| 平台 | macOS · Windows · Linux（**源码构建**；尚无签名安装包，见 `docs/STATUS.md` §分发） |
| 数据网格 | 服务端分页、列筛选/条件构造、多列排序、列宽与顺序记忆、行内编辑、区域选择、冻结列；**Filter & Sort 内嵌生成器**（显式 Apply、Sort By 芯片） |
| 写操作安全 | SQL 预览 → 单事务执行 → 失败回滚 → 保存后反向撤销；危险语句分级 + 两级确认 |
| 导航 | 连接 → 库 → 分组三级树；MySQL / MariaDB / PostgreSQL / SQL Server 多库可切换（双击库即切），SQLite 单库平铺；页签与状态栏带库名，⭐ R54 起界面上十个说得出「是哪家」的表面各顶**自己那一家**的图形与品牌色，不用读字就知道连的是哪家。⭐ R52 契约第 9 条把「切过去之后语句真的落在那个库」补成了真库证据（此前只有连接对象换库名的单测） |
| 结构编辑 | 加列/改列/重命名/删列、索引、外键、触发器、CHECK、表注释，全部单事务 + 联动刷新 |
| SQL 编辑器 | 语法高亮、**随库上下文的自动补全**（⭐ R57-a：表 / 视图 / 列 / 例程 / 关键字 —— `.` 后自动弹、`⌘空格` 强弹，认不出的限定符不猜）、**选中执行**（⭐ R57-b：有选区只跑选区，没选区跑光标所在语句；危险确认与状态栏回显读的是同一份文本）、多语句结果页签、执行计划、错误定位、查询历史、代码片段；**编辑器 / 结果带分栏可拖且记住**（⭐ R57-g：默认比例按参照帧逐像素量出 0.463，两条最小高钉住「拖到底也还能用」，记忆只认「在分隔条上真的拖过」—— 窗口太矮时布局夹出来的比例不算用户的选择）；已保存查询是对象页（4 列 + 设计/新建/删除） |
| 导入导出 | CSV / TSV / JSON Lines / SQL / xlsx / XML / HTML，字段映射、按目标列类型转换、坏行报告；**查询结果三种范围 × 六种格式**（⭐ R57-d：本页 / 选中行 / 全部结果，格式挂在系统保存对话框的扩展名档上，SQL(INSERT) 那一对查询结果明确不给 —— 没有目标表名写不出能执行的文件） |
| 凭据 | 存系统凭据库（macOS Keychain / Windows Credential Manager / secret-tool），**不落盘明文** |
| SSH 隧道 | ⭐ R55：连接可以先经**跳板机**再落到数据库 —— 纯 Java 隧道引擎，不调用系统的 `ssh` 可执行文件（「连不上」不该取决于用户装了什么）。跳板地址 / 端口 / 用户 / 认证方式在连接向导的 SSH 页录入；跳板口令与私钥口令短语只进系统凭据库、**不落进连接档案**；主机密钥按 OpenSSH 的 `known_hosts` 记录，密钥变更会拦下并说明，不折进「连接已断开」。⚠️ 私钥格式限 RSA / ECDSA（内置 SSH 库不支持 ed25519，界面上就明写着）。五家真库各跑过一遍「经进程内跳板机连上」 |
| 主题 | 暗/亮双主题（跟随系统）、四档密度、111 个设计令牌单一真相 |
| 键盘与可访问性 | ⌘K 命令面板、六区焦点顺序、逐页可朗读名称 |
| 界面语言 | 英文（默认）· 简体中文 |

## 接下来（按对用户价值排序，非按实现难度）

1. ~~**SSH 隧道**~~ —— ✅ **R55-c 交付（2026-11-03，G5a）**：选型 Apache MINA `sshd-core` 2.20.1
   （Apache-2.0，评估与「为什么不 shell 出系统的 `ssh -L`」记在 `docs/COMPONENT-SELECTION.md`）。
   引擎在 `SshTunnel`：`JdbcSession.open` 先起隧道、再把 host/port 换成 `127.0.0.1:临时端口`，
   连库失败即关掉隧道（不留一个还挂着 SSH 会话与本机端口的「失败连接」）。秘密按类型分家：
   `SshConfig`（无秘密，进档案）/ `SshSecrets`（口令与口令短语，只进凭据库）/ `SshEndpoint`（驱动层，
   `toString` 打码），拼装口只有 `ConnectionProfile.spec` 一处。失败分类不猜文本：隧道起不来与主机密钥
   变更各有独立一档（D-32 那种「三种失败都写着 communications link failure」的形状不再复现）。

   （`p5-connect-ssh` 口令分支、`p5-connect-ssh-key` 私钥分支）。⚠️ 已知边界：**私钥只吃 RSA / ECDSA**，
   内置库对 ed25519 是「文件读得出、交出 0 把密钥」，所以提示词、字段旁的说明、引擎报错三处一起把

## 明确不做

- **不内嵌 WebView / 不做 Electron 化**：原生桌面是这个项目存在的理由。
- **不启本地 HTTP 服务**：所有数据经 JDBC。
- **不做云端协作 / 多用户权限体系**：这是桌面单用户工具的定位。
- **不把 AI 助手做成核心依赖**：SQL 由用户书写，安全门禁由本地规则保证，不交给模型判断。
- **不做 Automation（计划任务调度）、Model ER 全量编辑器、Data Generation（测试数据填充）**
  （2026-11-01 裁定，P1）：这三面在 Navicat 里是独立子系统，各自要一套自己的持久化格式与编辑器，
  而它们服务的是「团队批量作业 / 逆向建模 / 造压测数据」——都不是这个桌面客户端的定位。
  处理方式不是删入口，是**保留入口 + 如实说明页**：点进去看得见「这一版没有这个能力」，
  看不见的是一张摆好却什么都不做的空表单。
