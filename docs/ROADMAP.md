# Roadmap

> 公开路线：**现在支持什么 · 接下来做什么 · 明确不做什么**。
> 内部执行清单（逐轮拆解、验收口径）不在本仓库发布，本文只对外承诺结果。

---

## 已支持

| 能力 | 说明 |
|---|---|
| 数据库 | SQLite · MySQL 5.7/8.x · PostgreSQL |
| 形态 | 原生桌面（Java 25 + JavaFX 25），**不内嵌浏览器、不启本地 HTTP 端口** |
| 平台 | macOS · Windows · Linux（**源码构建**；尚无签名安装包，见 `docs/STATUS.md` §分发） |
| 数据网格 | 服务端分页、列筛选/条件构造、多列排序、列宽与顺序记忆、行内编辑、区域选择、冻结列；**Filter & Sort 内嵌生成器**（显式 Apply、Sort By 芯片） |
| 写操作安全 | SQL 预览 → 单事务执行 → 失败回滚 → 保存后反向撤销；危险语句分级 + 两级确认 |
| 导航 | 连接 → 库 → 分组三级树；MySQL / MariaDB / PostgreSQL / SQL Server 多库可切换（双击库即切），SQLite 单库平铺；页签与状态栏带库名 |
| 结构编辑 | 加列/改列/重命名/删列、索引、外键、触发器、CHECK、表注释，全部单事务 + 联动刷新 |
| SQL 编辑器 | 语法高亮、当前语句执行、多语句结果页签、执行计划、错误定位、查询历史、代码片段；已保存查询是对象页（4 列 + 设计/新建/删除） |
| 导入导出 | CSV / TSV / JSON Lines / SQL / xlsx，字段映射、按目标列类型转换、坏行报告 |
| 凭据 | 存系统凭据库（macOS Keychain / Windows Credential Manager / secret-tool），**不落盘明文** |
| 主题 | 暗/亮双主题（跟随系统）、四档密度、110 个设计令牌单一真相 |
| 键盘与可访问性 | ⌘K 命令面板、六区焦点顺序、逐页可朗读名称 |
| 界面语言 | 英文（默认）· 简体中文 |

## 接下来（按对用户价值排序，非按实现难度）

1. **Oracle / SQL Server / MariaDB 真库验证** —— 方言与目录查询已实现并有单测门禁，三种方言的真库契约待补（需要 Docker 环境）。
2. **SSH 隧道** —— 连接生产库的实际前提（当前连接向导里如实标注未实现）。
3. **SSL/TLS 完整化** —— 当前写入驱动属性，证书链校验与 SNI 待补。
4. **数据生成（测试数据填充）** —— 开发者高频需求。
5. **数据脱敏导出** —— 合规场景。
6. **ER 图** —— 评估中。
7. **发布工程** —— 三平台安装包、自动更新、代码签名与公证（后两项受外部证书资源限制）。
8. **R43-c 去臃肿收尾** —— R43-b 帧目视留下的两处，都不是新能力而是**看着不对**：
   ① 数据网格工具条右端在 1280px 帧上露出一颗**只有下拉箭头、没有图标也没有文字**的 `▾`
   （`p2-users` / `p2-filter-sort` 同一位置；R43-b 之前就有，非本轮引入）——
   它既没有图标也没有文字，用户无从知道点下去是哪一颗键的动作，属 §11 说的骗人控件形态；
   身份要连着 N18/N19 的折叠判据一起查（右端那颗是视图菜单 `≡`，箭头不该在它左边）。
   ② 建表弹窗在只有四列时，字段网格与属性面板之间空出约 150px（`p6-new-table-fields` 同一帧可见），
   与类型页是同一类问题 —— 内容止于上半屏，剩下的落在中间而不是两端。

## 明确不做

- **不内嵌 WebView / 不做 Electron 化**：原生桌面是这个项目存在的理由。
- **不启本地 HTTP 服务**：所有数据经 JDBC。
- **不做云端协作 / 多用户权限体系**：这是桌面单用户工具的定位。
- **不把 AI 助手做成核心依赖**：SQL 由用户书写，安全门禁由本地规则保证，不交给模型判断。

## 已知限制

冷启动未达 <2s 目标（实测 3.5–3.9s，瓶颈在 JVM/Toolkit 与首趟 CSS/布局，非业务代码）；
jlink 自定义运行时暂不可行（RichTextFX / ControlsFX 为自动模块）；
无主键表与视图只读；转置视图只读；本页搜索只作用当前页。
完整清单见 [docs/STATUS.md](STATUS.md)。
