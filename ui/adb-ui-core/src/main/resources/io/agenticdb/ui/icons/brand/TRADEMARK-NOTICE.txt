厂商商标资产 —— 署名、出处与改动说明
TRADEMARK NOTICE / PROVENANCE FOR icons/brand/
================================================================

本目录里的十一枚 SVG 涉及**第三方商标**，不是本项目的原创图形，也不属于 ISC / Lucide
那类可自由再分发的素材（那两个目录的署名见 ../color/ISC-LICENSE.txt 与
../lucide/ISC-LICENSE.txt）。它们由 R63-3（2026-11-04）按「全部表面换，我拍平素材」
的拍板引入：六家数据库在向导磁贴、导航树连接节点、连接管理器、页签、状态栏、
库选择器上顶的都是各家官方标志，识别方式从「同风格自绘图形 + CSS 品牌色」
改成「官方标志 + 字面官方色」。EXT P1/P2 增补 Redis 与四家对象存储：
redis.svg 与 aws-s3.svg / aliyun-oss.svg / qiniu.svg / tencent-cos.svg 共五枚
**是中性几何占位件，不是厂商官方标志**（见下方逐枚说明），R4 发布前必须换成
遵守各家品牌使用规范的官方矢量件。

二、我们对每一枚做了什么（全部是「拍平」，不重绘、不改形状）
----------------------------------------------------------------
1. 把 transform / translate / scale 烘焙进路径坐标；
2. 渐变（linearGradient / radialGradient）取其主色，写成字面 #rrggbb；
3. 去掉 clipPath / mask / switch / foreignObject / 位图 / 文字，只留 <path>；
4. 视框统一成 viewBox="0 0 1000 1000"，居中留 3% 边距；非方形的标志（MariaDB
   1.50:1、Oracle 1.60:1）按长边 letterbox，所以它们在方形槽位里上下会留白；
5. 弧线 A 按 W3C SVG 1.1 F.6.5 / F.6.6 展开成三次贝塞尔，命令全部转绝对
   （JavaFX 的 SVGPath 只认 M L H V C S Q Z）；
6. 除 oracle 一枚（见上）外，官方色值一个没动。

拍平脚本（flatten.py）是一次性工具，没有入库；上面第 1～5 条就是它的口径，
门禁 BrandIconTest 逐条守着这些性质。


三、明码写下的风险（拍板时已知并接受）
----------------------------------------------------------------
1. MariaDB、Microsoft 的商标指引不允许改色，也不允许做衍生件。我们没改色，
   但做了「裁掉字标 / 拍平渐变 / 换视框」的衍生处理 —— 严格口径下这仍是修改。
2. Oracle 一枚改了色（#EE0004 → #E55844），依据是它自家站点图标；可争议。
3. MySQL / PostgreSQL / Oracle 三枚的出处未逐字节核实（第三方复刻件）。
   ⚠️ 对外发布（公开下载、演示、销售）之前，这三枚应当换成各家品牌页的原始
   矢量件，并重跑 BrandIconTest + VendorGlyphTest。目前状态只适用于内部构建。
4. 这些资产会打进 jar。本文件与资源同目录，就是为了出事时能拿出当时的口径。


四、界面侧的配套约束（代码里已经钉住，不是口头承诺）
----------------------------------------------------------------
· 商标不吃主题、不吃 CSS 角色类：颜色只存在于资产里，走完两档 CSS 之后算出的
  还是同一组官方色 —— VendorGlyphTest.theOfficialColorsSurviveCssInBothThemes。
  代价：暗色档下商标不会变亮，可读性靠下面那条。
· 暗色档侧栏底 #172033 压不住 MySQL 的 #00546B（1.9:1）和 MariaDB 的 #1F305F
  （1.2:1），于是给一层浅色底板 -adb-brand-plate（app.css 的 .adb-brand-plate）：
  改的是「它坐的表面」，标志本身一个像素没动。
· 唯一出口是 ConnectionCatalog.graphic(kind, size)；任何表面直接取资产就是绕过
  登记表 —— VendorGlyphTest.onlyTheSharedOutletAsksForBrandMarks。
· 目录里的资产必须与登记表一一对应，多一枚没人引用的商标也算风险敞口 ——
  VendorGlyphTest.brandDirectoryHoldsExactlyTheRegisteredMarks。
